# Screenshots

Add evidence screenshots here before submitting, e.g.:

- `cli_demo_1.png` — terminal screenshot of a full conversation covering at least 3 different
  FAQ intents
- `cli_demo_escalation.png` — screenshot showing the escalation-to-human trigger firing on a
  complaint or explicit human request
- `accuracy_test_run.png` — terminal screenshot of `python -m tests.test_accuracy` showing the
  12/12 result
- `accuracy_test_log.png` — screenshot of the rendered `docs/accuracy_test_log.md` on GitHub

To generate the CLI screenshots, run:

```bash
python -m src.cli
```

and paste in a few of the sample questions from `tests/sample_questions.json`, then screenshot
the terminal.
